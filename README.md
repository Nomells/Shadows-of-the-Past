# 🎭 Тени прошлого (Shadows of the Past)

**2D top-down психологический хоррор** на **C++17 + raylib 5.x**.
Вдохновлён **Darkwood**: тьма, ограниченный обзор, безумие как главная угроза.
Всё в игре — процедурное: графика, звук, музыка. Без внешних ассетов.

---

## 📖 О проекте

Слава возвращается в деревню детства через 10 лет после исчезновения сестры Анны.
Мир игры — его собственный бред, вызванный чувством вины.
**Четыре концовки**, каждая раскрывает свою грань правды.

**Ключевые особенности:**

- 🌑 **Тьма и конус обзора** — видно только то, что перед тобой.
- 🧠 **Безумие** — главная угроза, а не здоровье.
- 🎭 **4 концовки** — Redemption, Sacrifice, Madness, Truth.
- 🎬 **Многослойная сцена** — интро, катсцена, анимация задач.
- 👤 **Реальные тени** — свет обтекает стены и деревья (shadow volumes).
- 🎨 **Постобработка** — vignette, film grain, chromatic aberration.
- 🔊 **Процедурный звук и музыка** — генерируются в рантайме.
- 💾 **Сохранения, настройки, рекорды** — всё работает.
- 🖥 **Единственный способ закрыть игру — Exit в меню**.

Полный дизайн-документ: [docs/PROJECT.md](docs/PROJECT.md).

## 🚀 Быстрый старт

### Требования

| Компонент | Версия |
|-----------|--------|
| Компилятор | GCC 9+ / Clang 10+ / MSVC 2019+ |
| CMake | 3.15+ |
| raylib | 5.x |
| C++ | 17 |

### Установка raylib

**Linux (Ubuntu/Debian):**
```bash
sudo apt install libraylib-dev
```

**macOS (Homebrew):**
```bash
brew install raylib
```

**Windows:**
Скачать с [github.com/raysan5/raylib/releases](https://github.com/raysan5/raylib/releases),
распаковать в `C:/raylib`, подключить в проект.

### Сборка через CMake

```bash
git clone https://gitlab.com/<твой_юзер>/shadows-of-the-past.git
cd shadows-of-the-past
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/ShadowsOfThePast
```

### Сборка в Visual Studio

1. Открой **`Shadows of the Past.slnx`**.
2. Платформа: **x64**, конфигурация: **Release**.
3. **Build → Rebuild Solution** (`Ctrl+Shift+B`).
4. **F5** — запуск.

Собранный `.exe` появится в:
```
x64\Release\Shadows of the Past.exe
```
Он самодостаточный — raylib слинкован статически.

## 🎯 Игровой процесс

### Цель

Найти **3 ключа** (Rusty, Hospital, Church), попасть в церковь,
победить **Тень** и сделать финальный выбор на алтаре.

### Локации

| # | Локация | Что найти |
|---|---------|-----------|
| 1 | **Дом бабушки** | Rusty Key, дневник, фото |
| 2 | **Школа** (2 этажа) | Hospital Key, 3 записки |
| 3 | **Больница** | Church Key, медкарта |
| 4 | **Церковь** | Holy Symbol, алтарь, босс |
| 5 | **Скрытая комната** | Хроники (для финала Truth) |
| + | **Деревня** | Хаб, NPC Странник |

### Механики

- **HP** — падает от волков и теней.
- **Sanity** — падает в темноте и рядом с тенями. При нуле — Game Over «MADNESS».
- **Score** — 100 за записку, 500 за ключ, 200 за волка, 1000 за финал + бонус за скорость.
- **Враги** — тени (патруль → погоня), волки (агрессивные), босс-тень в церкви.

## 🏗 Архитектура (кратко)

Игра построена на **сценах** (`Scene` — базовый класс):
- `Game` хранит текущую сцену и переключает её.
- `GameContext` — общий контекст.
- Каждая сцена изолирована: `update(dt)` + `draw()`.

**Управление памятью:** RAII, объекты на стеке, `std::unique_ptr` для динамических.

**Графика:** `GenImageColor`, `GenImagePerlinNoise`, `LoadTextureFromImage`.
Никаких внешних PNG.

**Звук:** `LoadSoundFromWave` с процедурными Wave'ами,
`LoadMusicStreamFromMemory` для ambient.
